# Sixty by DevMate: portal

The Sixty dashboard (portal.devmatesolutions.com): WhatsApp and Instagram inbox with the Freya AI agent, AI voice calls, lead scoring, client workspaces and onboarding.

- Setup and environment variables: see `.env.example`.
- Client workspaces and onboarding: see `docs/workspaces.md`.
- Database: run the SQL files in `supabase/` (platform.sql, whatsapp.sql, workspaces.sql, instagram.sql).
